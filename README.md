# UNIFEST 2026 — Interactive Event Website

A modern, dark-themed interactive landing page for UNIFEST 2026,
a University Cultural & Tech Fest.

## 🌐 Live Demo
[View Site](https://keshoreg06-beep.github.io/interactive-event-website/)

## 📌 Features
- Animated loader screen
- Interactive floating background blobs (mouse parallax)
- Scroll reveal animations
- Smooth navigation
- Registration form
- Fully responsive

## 🛠️ Built With
- HTML5
- CSS3
- Vanilla JavaScript
